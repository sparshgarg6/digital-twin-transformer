# Local experiment outputs

Use this directory for checkpoints, generated samples, training logs, and result files. Everything here except this guide is ignored by Git.

Suggested layout: `artifacts/<session>/<run-id>/`.

Save the run configuration, corpus checksum, random seed, installed dependency versions, loss history, and a sample beside each checkpoint. Weights and generated text from private message experiments stay local too.

Only add reviewed, non-sensitive measurements to the public experiment log. There are no checkpoints or measured results yet.
